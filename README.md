# KTM Bike Showroom, Butwal 🏍️🔥

A modern, high-performance web experience for **KTM Bike Showroom, Butwal, Nepal**. Features interactive bike showcases, realistic engine audio rev simulations, comprehensive model specifications, EMI financing calculator, test ride bookings, and accessories showcase.

## 🚀 Features

- **Dynamic Bike Showcase**: Detailed view of the Duke, RC, and Adventure lineup (Duke 200/250/390, RC 200/390, 390 Adventure, 1390 Super Duke R).
- **Interactive Engine Audio Revving**: Web Audio engine rev sound effects for multiple models.
- **Interactive 3D / 360° Inspection & Color Switcher**: View different colorways and angles.
- **NPR EMI Calculator**: Loan tenure, down payment, interest calculation tailored for Nepal.
- **Test Ride & Service Booking**: Seamless booking interfaces.
- **Responsive & Dark-Themed**: KTM READY TO RACE orange & dark aesthetic.

## 🛠️ Built With

- HTML5 / CSS3 (Custom design system, animations & responsive grid)
- Vanilla JavaScript (Dynamic UI, Web Audio API, calculators, modals)
